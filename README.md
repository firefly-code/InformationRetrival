# Information Retrieval Pipeline

This repository contains our **information retrieval pipeline** for the **ROBUST 2004** and **OWI** datasets.

## Overview
The project consists of two similar Jupyter notebooks that perform retrieval on the two datasets:

- **robust_2004_retrival**  
  Implements the retrieval pipeline on the ROBUST 2004 dataset. This notebook also saves the trained model as a JSON file(**ltr_model.json**).

- **OWI_retrival**  
  Implements the retrieval pipeline on the OWI dataset. Loads the saved JSON model from the ROBUST 2004 notebook.
